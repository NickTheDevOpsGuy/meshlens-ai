# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the maintainer directly or use the repository's security advisory feature.
3. Provide a clear description of the vulnerability, steps to reproduce, and potential impact.
4. Allow a reasonable time for a fix before any public disclosure.

We appreciate your help in keeping Meshlens AI secure.
